Handboll Direkt

Integritetspolicy

Senast uppdaterad: 30 juli 2026

Den här policyn beskriver hur appen Handboll Direkt hanterar information. Appen är ett tränarverktyg för att rita taktik, skapa övningar och bygga träningspass.

1. Vem ansvarar

Appen tillhandahålls av Niklas Sälle. Kontakt för integritets- och supportfrågor: niklas.salle@outlook.com

2. Vilken information appen använder

Handboll Direkt samlar inte in data för reklam eller spårning. Informationen som kan sparas är sådan du själv skapar i appen, till exempel:

  • Namn och uppgifter om spelare i din trupp
  • Taktiker, övningar, träningspass och favoritmarkeringar
  • Bilder du lägger till (t.ex. omslagsbild eller logotyp)
  • Inställningar som färger och egna formationer

Om du delar en tavla eller ett träningspass till Bilder/Kamerarullen sparas filen lokalt på din enhet via Apples delningsfunktion.

3. Var informationen sparas

  • På din enhet: appens innehåll och vissa inställningar sparas lokalt.
  • I iCloud (CloudKit): när du är inloggad med ditt Apple‑ID kan trupp, taktiker, övningar och träningspass synkas via Apple iCloud, så att datan kan återställas om du byter eller raderar telefonen.

Vi har ingen egen server som samlar in eller analyserar ditt innehåll. iCloud hanteras av Apple enligt Apples villkor och integritetspolicy.

4. Varför informationen behövs

Informationen används endast för att appen ska fungera, till exempel för att:

  • visa och spara dina tavlor, övningar och pass
  • koppla spelare till brickor på planen
  • synka ditt bibliotek mellan dina enheter via iCloud
  • låta dig dela bilder eller film när du själv väljer att göra det

5. Delning med tredje part

Vi säljer inte din information och använder inte reklamnätverk eller spårning för marknadsföring. Data kan behandlas av Apple när du använder iCloud, delning eller sparande till Bilder.

6. Barn

Appen är ett verktyg för tränare och kräver ingen egen inloggning hos oss. Om du sparar namn på minderåriga spelare ansvarar du för att det sker på ett lämpligt sätt. Vi riktar inte marknadsföring till barn.

7. Radera data

Du kan:

  • ta bort enskilda övningar, taktiker, pass eller spelare i appen
  • använda Radera all data i Inställningar för att tömma appens lokala innehåll

Observera att innehåll som redan synkats till iCloud kan komma tillbaka om du är inloggad med samma Apple‑ID. För att ta bort iCloud-data helt kan du även hantera appdata via enhetens iCloud-inställningar.

8. Säkerhet

Vi vidtar rimliga åtgärder genom att använda Apples plattformssäkerhet och iCloud. Ingen metod är dock helt riskfri.

9. Ändringar

Den här policyn kan uppdateras vid behov. Datumet överst visar när den senast ändrades.
